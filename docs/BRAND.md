# HEC brand assets

Masters (high-resolution, not served): `docs/client/brand/`. Served derivatives are generated from them, trimmed and compressed.

## Palette (sampled from the mark)

| Token | Hex | Use |
|---|---|---|
| Gold | `#E4B42A` | Highlights, sparks, attention accents (not for body text on white) |
| Sky | `#4CA3D6` | Links on dark, cold accents |
| Blue | `#3C6CA8` | Primary actions (admin primary) |
| Navy | `#0E1B30` | Text, dark surfaces |
| Night | `#000C1E` | Darkest surface, browser theme colour |

## Which file where

| File | Where it is used |
|---|---|
| `public/images/brand/logo-horizontal.webp` | Site header (light), admin logo (light) |
| `public/images/brand/logo-horizontal-on-dark.webp` | Site header on dark surfaces, admin logo (dark mode) |
| `public/images/brand/mark-color.webp` | Compact header, loaders, intro animation, structured-data `logo` |
| `public/images/brand/mark-white.webp` | Footer and dark sections |
| `public/images/brand/mark-black.webp` | Print stylesheet (quotes, product sheets) |
| `public/images/brand/og-default.jpg` | Default Open Graph / social share image (1200×630) |
| `public/favicon.ico`, `public/favicon-32x32.png` | Browser tab |
| `public/apple-touch-icon.png` | iOS home screen |
| `public/icon-192.png`, `public/icon-512.png`, `public/icon-maskable-512.png` | `site.webmanifest` |
